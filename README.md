## About me

I'm Sam, a self-taught developer in Sydney. I came to software from customs, logistics and running a cleaning

## Meet Koda, my agent team

The part I'm proudest of isn't an app. It's how the apps get built.

**Koda** is the operator that runs my two Macs: a MacBook Air as home base and a Mac mini that does the builds,
simulators and overnight jobs, joined over Tailscale. Koda plans the work, routes it to the right model, and
keeps the record of what happened and why. Nothing merges on one model's word:

- **Independent review.** Every change goes through reviewers from a different model family than the one that
  wrote it, running read-only, until the verdict is a clean pass.
- **Evidence over claims.** A change ships with before-and-after proof and the exact commands that verified it.
- **Shared memory.** A lessons file every agent reads, so a fix learned once stays learned.
- **Recall.** A search index over every agent session, commit and lesson across both Macs (70,000+ records).
  Secrets are redacted before anything is stored, and a small model pulls out each error, its cause and its fix.
  So when an agent hits a problem, its first move is asking whether we've solved it before.
- **Guard rails.** Monthly spend caps on paid models, no secrets in code or logs, and a disk sweep that keeps
  both machines clean.
